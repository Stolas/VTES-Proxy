# vtes_proxy

A little script that generates a print-ready A4 PDF of [VTES](https://www.blackchantry.com/) proxy cards, at exact real-card size, using the [KRCG API](https://api.krcg.org).

## What it does

1. You give it a list of card names and quantities.
2. It looks each one up on the KRCG API (`https://api.krcg.org`) and downloads the official scan.
3. It crops/scales every image to the exact physical size of a real card (63.5mm × 88.9mm — standard trading-card size).
4. It tiles them onto A4 pages (3×3 = 9 cards per page) with thin cutting guide lines, so when printed at 100% and cut, the proxies are the same size as the real cards and fit in a sleeve next to them.
5. If a card isn't in the KRCG database yet (unreleased / spoiler card), it stops and asks you to supply a local image file for it.

## Usage

```
python vtes_proxy.py "6 Information Exchange" "6x Deadly Secrets" "1 Kaiser"
```

Or put your list in a text file (one entry per line, `#` comments allowed):

```
# decklist.txt
6 Information Exchange
6x Deadly Secrets
1 Kaiser
```

```
python vtes_proxy.py --list decklist.txt -o proxies.pdf
```

### Options

| Flag | Default | What it does |
|---|---|---|
| `-o`, `--output` | `vtes_proxies.pdf` | Output PDF path |
| `--card-width` | `63.5` | Card width in mm |
| `--card-height` | `88.9` | Card height in mm |
| `--margin` | `5` | Minimum page margin in mm |
| `--gap` | `0` | Gap between cards in mm |
| `--no-cutlines` | off | Skip the cutting guide lines |

**Print at 100% / "actual size."** If your print dialog does "fit to page" the cards will come out the wrong size and won't match your sleeves.

## Known quirks

- When it asks for an image for an unreleased card, it wants a **local file path**, not a URL. If you paste a direct image link it'll fail to open it and ask again — download the image first, then give it the local path. (See the tested run below, this happened live.)
- Card name matching is only as good as KRCG's autocomplete. If a card isn't found and there's no single obvious suggestion, it'll just ask you for a local file.
